# XOne SDK Docs

Developer documentation site for [`@xone/sdk`](../sdk).

```bash
pnpm --filter @xone/sdk-playground dev
# → http://localhost:5182

pnpm --filter @xone/sdk-playground run deploy
# → https://xone-sdk-docs.pages.dev
```

Renders `apps/sdk/README.md` with a grouped API sidebar (Getting started → Client → Agent → Tools → Reference).
